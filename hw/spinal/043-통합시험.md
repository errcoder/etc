검증 대상은 다음 네 가지입니다.

1. `ADD`와 EX/MEM, MEM/WB forwarding
2. `LOAD`와 load-use hazard 및 1-cycle stall
3. `BEQ`와 branch 처리
4. 최종 register 값과 write-back 순서

기존 5-stage CPU에 기능을 무리하게 한꺼번에 추가하지 않고, 명령어 인코딩부터 프로그램의 실행 결과까지 먼저 확정하겠습니다.

## 1. 통합 테스트 프로그램

초기 상태는 기존 테스트와 동일하게 유지합니다.

```
R0 = 0x02
R1 = 0x00
R2 = 0x00
R3 = 0x10

MEM[2] = 0x55
```

이번 프로그램은 다음과 같습니다.

| PC | 명령어                 | 목적              |
| -- | ------------------- | --------------- |
| 0  | `LOAD R1, [R0 + 0]` | RAM 읽기          |
| 1  | `ADD R2, R1, R3`    | Load-use hazard |
| 2  | `BEQ R0, R0, +2`    | Branch taken    |
| 3  | `ADD R3, R0, R0`    | Branch로 건너뛸 명령  |
| 4  | `ADD R3, R2, R0`    | Branch target   |

PC 2의 분기는 항상 참이므로 PC 3은 실행되면 안 됩니다.

## 2. Instruction encoding

기존에 확정한 명령어 형식을 그대로 사용합니다.

| PC | 명령어                 | Encoding |
| -- | ------------------- | -------- |
| 0  | `LOAD R1, [R0 + 0]` | `0x5400` |
| 1  | `ADD R2, R1, R3`    | `0x09C0` |
| 2  | `BEQ R0, R0, +2`    | `0x4002` |
| 3  | `ADD R3, R0, R0`    | `0x0C00` |
| 4  | `ADD R3, R2, R0`    | `0x0E00` |

분기 인코딩은 다음과 같습니다.

```
BEQ R0, R0, +2

opcode = 4       → 0x4000
rs1    = 0       → 0x0000
rs2    = 0       → 0x0000
offset = 2       → 0x0002

                    0x4002
```

## 3. 기대하는 실행 결과

예상 Write Back 순서

1. WB #1 — LOAD

   `R1 <= 0x55`
2. WB #2 — ADD

   `R2 <= 0x65`
3. WB #3 — Branch target ADD

   `R3 <= 0x67`

최종 Register 값

| Register | Expected |
| -------- | -------- |
| R0       | `0x02`   |
| R1       | `0x55`   |
| R2       | `0x65`   |
| R3       | `0x67`   |

필수 검증 조건

- Load-use stall: 정확히 1회
- Branch taken: 1회
- PC 3 명령어: 실행되지 않음
- Write Back: 총 3회

## 4. 이번 통합에서 주의할 점

기존 `FiveStageLoadCpu`는 `LOAD`, `ADD`, stall, forwarding까지 구현되어 있지만 아직 BEQ와 branch flush가 들어 있지 않습니다. 따라서 ROM 명령어만 바꾸면 통합 테스트가 되는 것은 아닙니다.

이번에는 다음 순서로 구현하겠습니다.

1. 기존 CPU에 `BEQ` decode와 branch target 계산 추가
2. 분기 확정 시 잘못 가져온 명령어를 flush
3. stall과 branch가 동시에 발생하는 경우의 제어 우선순위 확인
4. 위 프로그램으로 전체 시뮬레이션 및 assertion 검증

특히 branch flush와 load-use stall의 우선순위를 명확히 정해야 합니다. 이 부분까지 포함해 다음 단계에서 통합된 `FiveStageLoadCpu.scala`와 Simulation 전체 코드를 작성하겠습니다.

이번 단계에서는 기존 `FiveStageLoadCpu`에 BEQ와 Branch Flush를 통합하겠습니다.

핵심은 분기 명령을 EX 단계에서 판정하고, 분기가 참이면 잘못 가져온 명령어를 제거한 뒤 PC를 분기 목적지로 변경하는 것입니다.

이번 통합 프로그램에서는 다음 세 기능이 연속해서 동작해야 합니다.

- LOAD 직후 ADD의 의존성으로 1-cycle stall
- ADD 결과를 MEM/WB에서 forwarding
- BEQ taken으로 잘못 가져온 명령어를 flush

먼저 한 가지 중요한 수정 사항이 있습니다. 기존 명령어 형식에서 BEQ의 레지스터 필드는 R-type과 다릅니다. 따라서 BEQ의 `rs1`, `rs2`를 별도로 decode해야 합니다.

## 1. 통합 프로그램과 인코딩

```
PC 0 : LOAD R1, [R0 + 0]
PC 1 : ADD  R2, R1, R3
PC 2 : BEQ  R0, R0, +2
PC 3 : ADD  R3, R0, R0    // flush되어야 함
PC 4 : ADD  R3, R2, R0    // branch target
```

| PC | 명령어               | Encoding |
| -- | ----------------- | -------- |
| 0  | LOAD R1, [R0 + 0] | `0x5400` |
| 1  | ADD R2, R1, R3    | `0x09C0` |
| 2  | BEQ R0, R0, +2    | `0x4002` |
| 3  | ADD R3, R0, R0    | `0x0C00` |
| 4  | ADD R3, R2, R0    | `0x0E00` |

분기 목적지는 `branch PC + offset`, 즉 `2 + 2 = 4`입니다.

## 2. 최종 통합 `FiveStageLoadCpu.scala`

기존 CPU를 부분 수정하는 것보다, 아래 코드로 파일 전체를 교체하는 편이 안전합니다.

```
import spinal.core._

class FiveStageLoadCpu extends Component {

  val io = new Bundle {
    val run = in Bool()

    val loadEnable  = in Bool()
    val loadAddress = in UInt(2 bits)
    val loadData    = in Bits(8 bits)

    val pc = out UInt(4 bits)
    val stall = out Bool()
    val branchTaken = out Bool()

    val wbEnable  = out Bool()
    val wbAddress = out UInt(2 bits)
    val wbData    = out Bits(8 bits)

    val reg0 = out Bits(8 bits)
    val reg1 = out Bits(8 bits)
    val reg2 = out Bits(8 bits)
    val reg3 = out Bits(8 bits)
  }

  // ==========================================================
  // Register File
  // ==========================================================

  val registers = Vec(
    Reg(Bits(8 bits)) init(0),
    Reg(Bits(8 bits)) init(0),
    Reg(Bits(8 bits)) init(0),
    Reg(Bits(8 bits)) init(0)
  )

  // ==========================================================
  // Instruction ROM
  //
  // R-type:
  // [15:12] opcode
  // [11:10] rd
  // [ 9: 8] rs1
  // [ 7: 6] rs2
  //
  // LOAD:
  // [15:12] opcode
  // [11:10] rd
  // [ 9: 8] rs1
  // [ 7: 0] offset
  //
  // BEQ:
  // [15:12] opcode
  // [11:10] rs1
  // [ 9: 8] rs2
  // [ 7: 0] offset
  //
  // opcode:
  // 0000 = ADD
  // 0100 = BEQ
  // 0101 = LOAD
  // ==========================================================

  val rom = Mem(Bits(16 bits), wordCount = 16)

  rom.init(
    Seq(
      B"16'h5400", // 0: LOAD R1, [R0 + 0]
      B"16'h09C0", // 1: ADD  R2, R1, R3
      B"16'h4002", // 2: BEQ  R0, R0, +2
      B"16'h0C00", // 3: ADD  R3, R0, R0 (flushed)
      B"16'h0E00", // 4: ADD  R3, R2, R0 (target)
      B"16'h0000", // 5
      B"16'h0000", // 6
      B"16'h0000", // 7
      B"16'h0000", // 8
      B"16'h0000", // 9
      B"16'h0000", // 10
      B"16'h0000", // 11
      B"16'h0000", // 12
      B"16'h0000", // 13
      B"16'h0000", // 14
      B"16'h0000"  // 15
    )
  )

  // ==========================================================
  // Data RAM
  // ==========================================================

  val dataMem = Mem(Bits(8 bits), wordCount = 16)

  dataMem.init(
    Seq(
      B"8'h00", // 0
      B"8'h00", // 1
      B"8'h55", // 2
      B"8'h00", // 3
      B"8'h00", // 4
      B"8'h00", // 5
      B"8'h00", // 6
      B"8'h00", // 7
      B"8'h00", // 8
      B"8'h00", // 9
      B"8'h00", // 10
      B"8'h00", // 11
      B"8'h00", // 12
      B"8'h00", // 13
      B"8'h00", // 14
      B"8'h00"  // 15
    )
  )

  // ==========================================================
  // Program Counter / Fetch
  // ==========================================================

  val pcReg = Reg(UInt(4 bits)) init(0)

  val fetchInstruction = rom.readAsync(pcReg)

  // ==========================================================
  // IF / ID
  // ==========================================================

  val ifIdValid = Reg(Bool()) init(False)

  val ifIdPc = Reg(UInt(4 bits)) init(0)

  val ifIdInstruction = Reg(Bits(16 bits)) init(0)

  // ==========================================================
  // Decode
  // ==========================================================

  val decOpcode = ifIdInstruction(15 downto 12)

  val decIsAdd = decOpcode === B"4'b0000"
  val decIsBranch = decOpcode === B"4'b0100"
  val decIsLoad = decOpcode === B"4'b0101"

  // R-type / LOAD fields

  val decRd = ifIdInstruction(11 downto 10).asUInt
  val decRs1 = ifIdInstruction(9 downto 8).asUInt
  val decRs2 = ifIdInstruction(7 downto 6).asUInt

  // BEQ fields

  val decBranchRs1 = ifIdInstruction(11 downto 10).asUInt
  val decBranchRs2 = ifIdInstruction(9 downto 8).asUInt

  val decOffset = ifIdInstruction(7 downto 0)

  // Select actual source register addresses.

  val decSourceA = UInt(2 bits)
  val decSourceB = UInt(2 bits)

  decSourceA := decRs1
  decSourceB := decRs2

  when(decIsBranch) {
    decSourceA := decBranchRs1
    decSourceB := decBranchRs2
  }

  // Source usage

  val decUsesRs1 = decIsLoad || decIsAdd || decIsBranch
  val decUsesRs2 = decIsAdd || decIsBranch

  val decWriteEnable = decIsLoad || decIsAdd

  // Register File read

  val decRegA = registers(decSourceA)
  val decRegB = registers(decSourceB)

  // ==========================================================
  // ID / EX
  // ==========================================================

  val idExValid = Reg(Bool()) init(False)

  val idExPc = Reg(UInt(4 bits)) init(0)

  val idExIsLoad = Reg(Bool()) init(False)
  val idExIsBranch = Reg(Bool()) init(False)

  val idExWriteEnable = Reg(Bool()) init(False)

  val idExRd = Reg(UInt(2 bits)) init(0)

  val idExRs1 = Reg(UInt(2 bits)) init(0)
  val idExRs2 = Reg(UInt(2 bits)) init(0)

  val idExRegA = Reg(Bits(8 bits)) init(0)
  val idExRegB = Reg(Bits(8 bits)) init(0)

  val idExOffset = Reg(Bits(8 bits)) init(0)

  // ==========================================================
  // EX / MEM
  // ==========================================================

  val exMemValid = Reg(Bool()) init(False)

  val exMemIsLoad = Reg(Bool()) init(False)
  val exMemWriteEnable = Reg(Bool()) init(False)

  val exMemRd = Reg(UInt(2 bits)) init(0)

  val exMemResult = Reg(Bits(8 bits)) init(0)

  // ==========================================================
  // MEM / WB
  // ==========================================================

  val memWbValid = Reg(Bool()) init(False)

  val memWbIsLoad = Reg(Bool()) init(False)
  val memWbWriteEnable = Reg(Bool()) init(False)

  val memWbRd = Reg(UInt(2 bits)) init(0)

  val memWbResult = Reg(Bits(8 bits)) init(0)

  // ==========================================================
  // Forwarding
  //
  // Priority:
  // 1. EX/MEM (only non-LOAD)
  // 2. MEM/WB
  // 3. Register File
  // ==========================================================

  val exForwardA = Bits(8 bits)
  val exForwardB = Bits(8 bits)

  exForwardA := idExRegA
  exForwardB := idExRegB

  // Operand A: rs1

  when(
    exMemValid &&
      exMemWriteEnable &&
      !exMemIsLoad &&
      (exMemRd === idExRs1)
  ) {
    exForwardA := exMemResult
  } otherwise {
    when(
      memWbValid &&
        memWbWriteEnable &&
        (memWbRd === idExRs1)
    ) {
      exForwardA := memWbResult
    }
  }

  // Operand B: rs2

  when(
    exMemValid &&
      exMemWriteEnable &&
      !exMemIsLoad &&
      (exMemRd === idExRs2)
  ) {
    exForwardB := exMemResult
  } otherwise {
    when(
      memWbValid &&
        memWbWriteEnable &&
        (memWbRd === idExRs2)
    ) {
      exForwardB := memWbResult
    }
  }

  // ==========================================================
  // EX
  // ==========================================================

  // ADD: Bits -> UInt arithmetic -> Bits

  val exAluResult =
    (exForwardA.asUInt + exForwardB.asUInt).asBits

  // LOAD effective address

  val exLoadAddress =
    exForwardA.asUInt + idExOffset.asUInt

  val exResult = Bits(8 bits)

  exResult := exAluResult

  when(idExIsLoad) {
    exResult := exLoadAddress.asBits
  }

  // ==========================================================
  // Branch decision
  //
  // Branch operands use the same forwarding paths as ADD.
  // Branch is resolved in EX.
  // ==========================================================

  val branchEqual = exForwardA === exForwardB

  val branchTaken =
    idExValid &&
      idExIsBranch &&
      branchEqual

  // This lesson uses positive branch offsets.
  // Target = branch instruction PC + offset.

  val branchTarget =
    idExPc + idExOffset(3 downto 0).asUInt

  // ==========================================================
  // Load-use hazard
  // ==========================================================

  val loadUseHazard =
    ifIdValid &&
      idExValid &&
      idExIsLoad &&
      idExWriteEnable &&
      (
        (
          decUsesRs1 &&
            (idExRd === decSourceA)
        ) ||
        (
          decUsesRs2 &&
            (idExRd === decSourceB)
        )
      )

  // ==========================================================
  // MEM
  // ==========================================================

  val dataMemAddress =
    exMemResult(3 downto 0).asUInt

  val memReadData =
    dataMem.readAsync(dataMemAddress)

  // ==========================================================
  // Debug registers
  // ==========================================================

  val stallPulse = Reg(Bool()) init(False)

  val branchPulse = Reg(Bool()) init(False)

  // ==========================================================
  // Sequential pipeline update
  // ==========================================================

  when(io.loadEnable) {
    registers(io.loadAddress) := io.loadData
  }

  when(io.run) {

    // --------------------------------------------------------
    // WB
    // --------------------------------------------------------

    when(memWbValid && memWbWriteEnable) {
      registers(memWbRd) := memWbResult
    }

    // --------------------------------------------------------
    // MEM -> WB
    // --------------------------------------------------------

    memWbValid := exMemValid
    memWbIsLoad := exMemIsLoad
    memWbWriteEnable := exMemWriteEnable
    memWbRd := exMemRd

    when(exMemIsLoad) {
      memWbResult := memReadData
    } otherwise {
      memWbResult := exMemResult
    }

    // --------------------------------------------------------
    // EX -> MEM
    // --------------------------------------------------------

    exMemValid := idExValid
    exMemIsLoad := idExIsLoad
    exMemWriteEnable := idExWriteEnable
    exMemRd := idExRd
    exMemResult := exResult

    // --------------------------------------------------------
    // Debug defaults
    // --------------------------------------------------------

    stallPulse := False
    branchPulse := False

    // --------------------------------------------------------
    // Branch has priority over a younger instruction's stall.
    //
    // A taken branch invalidates the younger instructions
    // in IF/ID and prevents the current IF/ID instruction
    // from entering ID/EX.
    // --------------------------------------------------------

    when(branchTaken) {

      // Flush IF/ID

      ifIdValid := False
      ifIdInstruction := 0
      ifIdPc := 0

      // Bubble ID/EX

      idExValid := False
      idExIsLoad := False
      idExIsBranch := False
      idExWriteEnable := False

      idExRd := 0
      idExRs1 := 0
      idExRs2 := 0

      idExRegA := 0
      idExRegB := 0
      idExOffset := 0
      idExPc := 0

      // Redirect PC

      pcReg := branchTarget

      branchPulse := True

    } elsewhen(loadUseHazard) {

      // ------------------------------------------------------
      // Insert one bubble into ID/EX
      // ------------------------------------------------------

      idExValid := False
      idExIsLoad := False
      idExIsBranch := False
      idExWriteEnable := False

      idExRd := 0
      idExRs1 := 0
      idExRs2 := 0

      idExRegA := 0
      idExRegB := 0
      idExOffset := 0
      idExPc := 0

      // Hold IF/ID and PC by making no assignments.

      stallPulse := True

    } otherwise {

      // ------------------------------------------------------
      // ID -> EX
      // ------------------------------------------------------

      idExValid := ifIdValid
      idExPc := ifIdPc

      idExIsLoad := ifIdValid && decIsLoad
      idExIsBranch := ifIdValid && decIsBranch
      idExWriteEnable := ifIdValid && decWriteEnable

      idExRd := decRd

      idExRs1 := decSourceA
      idExRs2 := decSourceB

      idExRegA := decRegA
      idExRegB := decRegB

      idExOffset := decOffset

      // ------------------------------------------------------
      // IF -> ID
      // ------------------------------------------------------

      ifIdValid := True
      ifIdPc := pcReg
      ifIdInstruction := fetchInstruction

      // ------------------------------------------------------
      // PC
      // ------------------------------------------------------

      pcReg := pcReg + 1
    }
  }

  // ==========================================================
  // Outputs
  // ==========================================================

  io.pc := pcReg

  io.stall := stallPulse
  io.branchTaken := branchPulse

  io.wbEnable := memWbValid && memWbWriteEnable
  io.wbAddress := memWbRd
  io.wbData := memWbResult

  io.reg0 := registers(0)
  io.reg1 := registers(1)
  io.reg2 := registers(2)
  io.reg3 := registers(3)
}
```

## 3. 통합 Simulation

파일명: `FiveStageLoadCpuSim.scala`

```
import spinal.core.sim._

object FiveStageLoadCpuSim {

  def main(args: Array[String]): Unit = {

    SimConfig
      .withWave
      .compile(new FiveStageLoadCpu)
      .doSim { dut =>

        dut.clockDomain.forkStimulus(period = 10)

        // ======================================================
        // Initial values
        // ======================================================

        dut.io.run #= false

        dut.io.loadEnable #= false
        dut.io.loadAddress #= 0
        dut.io.loadData #= 0

        // ======================================================
        // Initialize registers
        //
        // R0 = 0x02
        // R1 = 0x00
        // R2 = 0x00
        // R3 = 0x10
        // ======================================================

        def loadRegister(address: Int, value: Int): Unit = {
          dut.io.loadEnable #= true
          dut.io.loadAddress #= address
          dut.io.loadData #= value

          dut.clockDomain.waitSampling()
          sleep(1)

          dut.io.loadEnable #= false
        }

        loadRegister(0, 0x02)
        loadRegister(1, 0x00)
        loadRegister(2, 0x00)
        loadRegister(3, 0x10)

        // ======================================================
        // Start CPU
        // ======================================================

        dut.io.run #= true

        var cycle = 0
        var wbCount = 0
        var stallCount = 0
        var branchCount = 0

        val wbResults = scala.collection.mutable.ArrayBuffer.empty[(Int, Int)]

        // ======================================================
        // Observe pipeline
        // ======================================================

        while (wbCount < 3 && cycle < 30) {

          dut.clockDomain.waitSampling()
          sleep(1)

          cycle += 1

          val pc = dut.io.pc.toInt

          val stall = dut.io.stall.toBoolean
          val branchTaken = dut.io.branchTaken.toBoolean

          val wbEnable = dut.io.wbEnable.toBoolean
          val wbAddress = dut.io.wbAddress.toInt
          val wbData = dut.io.wbData.toInt

          if (stall) {
            stallCount += 1
            println(f"Cycle $cycle%2d : STALL")
          }

          if (branchTaken) {
            branchCount += 1
            println(f"Cycle $cycle%2d : BRANCH TAKEN -> PC=$pc%d")
          }

          if (wbEnable) {
            wbCount += 1

            wbResults += ((wbAddress, wbData))

            println(
              f"Cycle $cycle%2d : WB #$wbCount%d : " +
                f"R$wbAddress%d <= 0x$wbData%02X"
            )
          }

          if (!stall && !branchTaken && !wbEnable) {
            println(f"Cycle $cycle%2d : PC=$pc%d")
          }
        }

        // ======================================================
        // Timeout check
        // ======================================================

        assert(
          wbCount == 3,
          s"Timeout: expected 3 write-backs, got $wbCount"
        )

        // ======================================================
        // Commit final WB
        //
        // The observed MEM/WB output is committed to
        // the register file at the following clock edge.
        // ======================================================

        dut.clockDomain.waitSampling()
        sleep(1)

        // Stop CPU

        dut.io.run #= false

        dut.clockDomain.waitSampling()
        sleep(1)

        // ======================================================
        // Read final register values
        // ======================================================

        val r0 = dut.io.reg0.toInt
        val r1 = dut.io.reg1.toInt
        val r2 = dut.io.reg2.toInt
        val r3 = dut.io.reg3.toInt

        println()
        println(f"Final R0 = 0x$r0%02X")
        println(f"Final R1 = 0x$r1%02X")
        println(f"Final R2 = 0x$r2%02X")
        println(f"Final R3 = 0x$r3%02X")

        println()
        println(s"Stall count  = $stallCount")
        println(s"Branch count = $branchCount")
        println(s"WB count     = $wbCount")

        // ======================================================
        // Verify write-back sequence
        // ======================================================

        assert(
          wbResults(0) == ((1, 0x55)),
          f"WB #1 expected R1 <= 0x55, got R${wbResults(0)._1}%d <= 0x${wbResults(0)._2}%02X"
        )

        assert(
          wbResults(1) == ((2, 0x65)),
          f"WB #2 expected R2 <= 0x65, got R${wbResults(1)._1}%d <= 0x${wbResults(1)._2}%02X"
        )

        assert(
          wbResults(2) == ((3, 0x67)),
          f"WB #3 expected R3 <= 0x67, got R${wbResults(2)._1}%d <= 0x${wbResults(2)._2}%02X"
        )

        // ======================================================
        // Verify hazards and branch
        // ======================================================

        assert(
          stallCount == 1,
          s"Expected one load-use stall, got $stallCount"
        )

        assert(
          branchCount == 1,
          s"Expected one taken branch, got $branchCount"
        )

        assert(
          wbCount == 3,
          s"Expected three write-backs, got $wbCount"
        )

        // ======================================================
        // Verify final register values
        // ======================================================

        assert(r0 == 0x02, f"R0 expected 0x02, got 0x$r0%02X")
        assert(r1 == 0x55, f"R1 expected 0x55, got 0x$r1%02X")
        assert(r2 == 0x65, f"R2 expected 0x65, got 0x$r2%02X")
        assert(r3 == 0x67, f"R3 expected 0x67, got 0x$r3%02X")

        println()
        println("Five-stage pipeline integration test passed.")
      }
  }
}
```
