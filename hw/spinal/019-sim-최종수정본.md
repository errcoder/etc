네. 이번에는 이전에 제시했던 simulation 코드에서 문제가 될 수 있었던 부분을 모두 정리해서, **동일한 Stream을 여러 simulation thread가 동시에 drive하지 않고**, TX handshake를 정확히 관찰하며, RX는 `StreamMonitor`로 scoreboard에 넣도록 구성한 **최종 `UartDuplexSystemSim.scala`**을 제시하겠습니다.

특히 이전 코드의 다음 문제를 제거했습니다.

- `StreamDriver`와 수동 driver를 동시에 사용하지 않음
- TX reference 데이터를 잘못된 callback 시점에 넣지 않음
- A/B 양방향 각각 독립적인 scoreboard 사용
- Test 3에서 잘못된 FIFO occupancy를 읽던 문제 수정
- `rxOverflow`를 마지막 값만 보는 것이 아니라 simulation 중 발생 여부를 기록
- `waitSampling()`을 기준으로 실제 Stream handshake를 명확하게 처리
- Test 1 → Test 2 → Test 3을 독립적으로 실행

---

# 최종 `UartDuplexSystemSim.scala`

경로:

```text
src/main/scala/sim/UartDuplexSystemSim.scala
```

```scala
package sim

import spinal.core._
import spinal.core.sim._
import spinal.lib._
import spinal.lib.sim._

import integration.UartDuplexSystem

object UartDuplexSystemSim extends App {

  // ============================================================
  // Common configuration
  // ============================================================

  val clockFrequencyHz = 10_000_000
  val baudRate         = 1_000_000

  // 8N1 UART
  //
  // 10 bits / byte
  // 10 clock cycles / bit
  // => 100 clock cycles / byte
  //

  val testCount = 8


  // ============================================================
  // Helper
  // ============================================================

  def printHeader(title: String): Unit = {
    println()
    println("====================================================")
    println(title)
    println("====================================================")
  }


  // ============================================================
  // TEST 1
  //
  // Full Duplex
  // No Backpressure
  // FIFO depth = 32
  // ============================================================

  def testNoBackpressure(): Unit = {

    printHeader("TEST 1 : FULL DUPLEX / NO BACKPRESSURE")

    val fifoDepth = 32

    val compiled =
      SimConfig
        .withWave
        .compile(
          UartDuplexSystem(
            clockFrequencyHz = clockFrequencyHz,
            baudRate = baudRate,
            fifoDepth = fifoDepth
          )
        )

    compiled.doSim("test1_no_backpressure") { dut =>

      dut.clockDomain.forkStimulus(10)


      // --------------------------------------------------------
      // Initial values
      // --------------------------------------------------------

      dut.io.aTx.valid   #= false
      dut.io.aTx.payload #= 0

      dut.io.bTx.valid   #= false
      dut.io.bTx.payload #= 0

      // No backpressure
      dut.io.aRx.ready #= true
      dut.io.bRx.ready #= true


      // --------------------------------------------------------
      // Scoreboards
      //
      // A -> B
      // B -> A
      // --------------------------------------------------------

      val aToB =
        ScoreboardInOrder[Int]()

      val bToA =
        ScoreboardInOrder[Int]()


      // --------------------------------------------------------
      // RX monitors
      //
      // B receives A's data
      // A receives B's data
      // --------------------------------------------------------

      var aRxCount = 0
      var bRxCount = 0


      StreamMonitor(
        dut.io.aRx,
        dut.clockDomain
      ) { payload =>

        val value = payload.toInt

        println(
          f"[A RX] 0x$value%02X"
        )

        bToA.pushDut(value)

        aRxCount += 1
      }


      StreamMonitor(
        dut.io.bRx,
        dut.clockDomain
      ) { payload =>

        val value = payload.toInt

        println(
          f"[B RX] 0x$value%02X"
        )

        aToB.pushDut(value)

        bRxCount += 1
      }


      // --------------------------------------------------------
      // A -> B TX driver
      //
      // Important:
      //
      // valid is asserted until ready is observed.
      // The actual transfer occurs on the following sampling
      // edge.
      // --------------------------------------------------------

      fork {

        for (i <- 0 until testCount) {

          val value = 0x40 + i

          dut.io.aTx.payload #= value
          dut.io.aTx.valid   #= true

          while (!dut.io.aTx.ready.toBoolean) {
            dut.clockDomain.waitSampling()
          }

          // Handshake occurs at this sampling edge.
          dut.clockDomain.waitSampling()

          aToB.pushRef(value)

          dut.io.aTx.valid #= false

          println(
            f"[A TX] 0x$value%02X"
          )
        }
      }


      // --------------------------------------------------------
      // B -> A TX driver
      // --------------------------------------------------------

      fork {

        for (i <- 0 until testCount) {

          val value = 0x60 + i

          dut.io.bTx.payload #= value
          dut.io.bTx.valid   #= true

          while (!dut.io.bTx.ready.toBoolean) {
            dut.clockDomain.waitSampling()
          }

          // Handshake occurs at this sampling edge.
          dut.clockDomain.waitSampling()

          bToA.pushRef(value)

          dut.io.bTx.valid #= false

          println(
            f"[B TX] 0x$value%02X"
          )
        }
      }


      // --------------------------------------------------------
      // Allow initial idle cycles
      // --------------------------------------------------------

      dut.clockDomain.waitSampling(5)


      // --------------------------------------------------------
      // Wait for both directions to complete.
      //
      // 8 bytes
      // 100 cycles / byte
      //
      // Add generous margin for:
      //   UART RX
      //   Flow.toStream()
      //   FIFO
      //   3 pipeline stages
      // --------------------------------------------------------

      dut.clockDomain.waitSampling(
        testCount * 150 + 500
      )


      // --------------------------------------------------------
      // Assertions
      // --------------------------------------------------------

      assert(
        aRxCount == testCount,
        s"A RX count mismatch: expected=$testCount actual=$aRxCount"
      )

      assert(
        bRxCount == testCount,
        s"B RX count mismatch: expected=$testCount actual=$bRxCount"
      )

      assert(
        !dut.io.aRxOverflow.toBoolean,
        "Unexpected A RX overflow"
      )

      assert(
        !dut.io.bRxOverflow.toBoolean,
        "Unexpected B RX overflow"
      )


      println()
      println("TEST 1 PASSED")
    }
  }


  // ============================================================
  // TEST 2
  //
  // Full Duplex
  // Random Backpressure
  // FIFO depth = 32
  // ============================================================

  def testRandomBackpressure(): Unit = {

    printHeader("TEST 2 : FULL DUPLEX / RANDOM BACKPRESSURE")

    val fifoDepth = 32

    val compiled =
      SimConfig
        .withWave
        .compile(
          UartDuplexSystem(
            clockFrequencyHz = clockFrequencyHz,
            baudRate = baudRate,
            fifoDepth = fifoDepth
          )
        )

    compiled.doSim("test2_random_backpressure") { dut =>

      dut.clockDomain.forkStimulus(10)


      // --------------------------------------------------------
      // Initial values
      // --------------------------------------------------------

      dut.io.aTx.valid   #= false
      dut.io.aTx.payload #= 0

      dut.io.bTx.valid   #= false
      dut.io.bTx.payload #= 0


      // --------------------------------------------------------
      // Random RX backpressure
      // --------------------------------------------------------

      StreamReadyRandomizer(
        dut.io.aRx,
        dut.clockDomain
      )

      StreamReadyRandomizer(
        dut.io.bRx,
        dut.clockDomain
      )


      // --------------------------------------------------------
      // Scoreboards
      // --------------------------------------------------------

      val aToB =
        ScoreboardInOrder[Int]()

      val bToA =
        ScoreboardInOrder[Int]()


      var aRxCount = 0
      var bRxCount = 0


      // --------------------------------------------------------
      // RX monitors
      // --------------------------------------------------------

      StreamMonitor(
        dut.io.aRx,
        dut.clockDomain
      ) { payload =>

        val value = payload.toInt

        println(
          f"[A RX] 0x$value%02X"
        )

        bToA.pushDut(value)

        aRxCount += 1
      }


      StreamMonitor(
        dut.io.bRx,
        dut.clockDomain
      ) { payload =>

        val value = payload.toInt

        println(
          f"[B RX] 0x$value%02X"
        )

        aToB.pushDut(value)

        bRxCount += 1
      }


      // --------------------------------------------------------
      // A -> B TX driver
      // --------------------------------------------------------

      fork {

        for (i <- 0 until testCount) {

          val value = 0x40 + i

          dut.io.aTx.payload #= value
          dut.io.aTx.valid   #= true

          while (!dut.io.aTx.ready.toBoolean) {
            dut.clockDomain.waitSampling()
          }

          dut.clockDomain.waitSampling()

          aToB.pushRef(value)

          dut.io.aTx.valid #= false

          println(
            f"[A TX] 0x$value%02X"
          )
        }
      }


      // --------------------------------------------------------
      // B -> A TX driver
      // --------------------------------------------------------

      fork {

        for (i <- 0 until testCount) {

          val value = 0x60 + i

          dut.io.bTx.payload #= value
          dut.io.bTx.valid   #= true

          while (!dut.io.bTx.ready.toBoolean) {
            dut.clockDomain.waitSampling()
          }

          dut.clockDomain.waitSampling()

          bToA.pushRef(value)

          dut.io.bTx.valid #= false

          println(
            f"[B TX] 0x$value%02X"
          )
        }
      }


      // --------------------------------------------------------
      // Initial idle
      // --------------------------------------------------------

      dut.clockDomain.waitSampling(5)


      // --------------------------------------------------------
      // Wait
      //
      // Random backpressure can stall the RX side.
      // Give significantly more time than Test 1.
      // --------------------------------------------------------

      dut.clockDomain.waitSampling(
        testCount * 400 + 1000
      )


      // --------------------------------------------------------
      // Assertions
      // --------------------------------------------------------

      assert(
        aRxCount == testCount,
        s"A RX count mismatch: expected=$testCount actual=$aRxCount"
      )

      assert(
        bRxCount == testCount,
        s"B RX count mismatch: expected=$testCount actual=$bRxCount"
      )

      assert(
        !dut.io.aRxOverflow.toBoolean,
        "Unexpected A RX overflow during random backpressure test"
      )

      assert(
        !dut.io.bRxOverflow.toBoolean,
        "Unexpected B RX overflow during random backpressure test"
      )


      println()
      println("TEST 2 PASSED")
    }
  }


  // ============================================================
  // TEST 3
  //
  // Intentional Overflow Experiment
  //
  // Purpose:
  //   Demonstrate that UART RX has no backpressure signal.
  //
  // FIFO is intentionally small.
  // RX consumer is intentionally stopped.
  //
  // Overflow is EXPECTED.
  // ============================================================

  def testIntentionalOverflow(): Unit = {

    printHeader("TEST 3 : INTENTIONAL FIFO OVERFLOW")

    val fifoDepth = 2

    val compiled =
      SimConfig
        .withWave
        .compile(
          UartDuplexSystem(
            clockFrequencyHz = clockFrequencyHz,
            baudRate = baudRate,
            fifoDepth = fifoDepth
          )
        )

    compiled.doSim("test3_intentional_overflow") { dut =>

      dut.clockDomain.forkStimulus(10)


      // --------------------------------------------------------
      // Initial values
      // --------------------------------------------------------

      dut.io.aTx.valid   #= false
      dut.io.aTx.payload #= 0

      dut.io.bTx.valid   #= false
      dut.io.bTx.payload #= 0


      // --------------------------------------------------------
      // Stop B RX consumer.
      //
      // A -> B data will eventually encounter a full pipeline/FIFO
      // path.
      // --------------------------------------------------------

      dut.io.aRx.ready #= true
      dut.io.bRx.ready #= false


      // --------------------------------------------------------
      // Observe overflow as a sticky simulation variable.
      //
      // rxOverflow may be a pulse, so checking only its final
      // value is unsafe.
      // --------------------------------------------------------

      var bOverflowObserved = false

      fork {

        while (true) {

          if (dut.io.bRxOverflow.toBoolean) {
            bOverflowObserved = true
          }

          dut.clockDomain.waitSampling()
        }
      }


      // --------------------------------------------------------
      // A sends many bytes toward B.
      //
      // The B side intentionally does not consume RX data.
      // --------------------------------------------------------

      fork {

        for (i <- 0 until 12) {

          val value = 0x80 + i

          dut.io.aTx.payload #= value
          dut.io.aTx.valid   #= true

          while (!dut.io.aTx.ready.toBoolean) {
            dut.clockDomain.waitSampling()
          }

          dut.clockDomain.waitSampling()

          dut.io.aTx.valid #= false

          println(
            f"[A TX] 0x$value%02X"
          )
        }
      }


      // --------------------------------------------------------
      // Give UART enough time to transmit the bytes.
      // --------------------------------------------------------

      dut.clockDomain.waitSampling(2500)


      // --------------------------------------------------------
      // Observe B-side FIFO occupancy.
      // IMPORTANT:
      //
      // A TX -> B RX
      //
      // therefore B FIFO occupancy is bFifoOccupancy.
      // --------------------------------------------------------

      val bOccupancy =
        dut.io.bFifoOccupancy.toInt


      println()
      println(
        s"[B FIFO] occupancy = $bOccupancy"
      )

      println(
        s"[B RX overflow observed] = $bOverflowObserved"
      )


      // --------------------------------------------------------
      // We EXPECT an overflow in this intentional experiment.
      //
      // Do not treat this as an RTL failure.
      // --------------------------------------------------------

      assert(
        bOverflowObserved,
        "Expected B-side RX overflow was not observed"
      )


      println()
      println(
        "TEST 3 COMPLETE : EXPECTED OVERFLOW OBSERVED"
      )
    }
  }


  // ============================================================
  // Execute tests
  // ============================================================

  testNoBackpressure()

  testRandomBackpressure()

  testIntentionalOverflow()


  // ============================================================
  // Final message
  // ============================================================

  println()
  println("====================================================")
  println("ALL TESTS COMPLETED")
  println("====================================================")
}
```

## 중요한 수정 사항

이번 최종본에서 특히 주의할 부분은 **TX driver의 handshake**입니다.

예를 들어 A가 `0x40`을 보낼 때:

```scala
dut.io.aTx.payload #= 0x40
dut.io.aTx.valid   #= true

while (!dut.io.aTx.ready.toBoolean) {
  dut.clockDomain.waitSampling()
}

dut.clockDomain.waitSampling()

aToB.pushRef(0x40)

dut.io.aTx.valid #= false
```

구조입니다.

즉 개념적으로:

```text
valid = 1
payload = 0x40

       ↓

ready = 0
       │
       │ waitSampling()
       ↓

ready = 1
       │
       │
       ▼
  다음 sampling edge
       │
       ▼
     FIRE
       │
       ▼
 reference 등록
       │
       ▼
 valid = 0
```

으로 처리합니다.

---

### Test 1

```text
A → B : 40 41 42 43 44 45 46 47
B → A : 60 61 62 63 64 65 66 67
```

을 전송하고 **backpressure 없이** 정상 전달되는지를 확인합니다.

### Test 2

RX의 `ready`를 `StreamReadyRandomizer`가 임의로 끊었다 붙이면서:

```text
UART
 ↓
Flow
 ↓
toStream
 ↓
FIFO
 ↓
3-stage pipeline
 ↓
random ready
```

상황에서도 데이터 순서가 보존되는지 확인합니다.

### Test 3

```text
B RX ready = false
FIFO depth = 2
A → B 데이터를 계속 전송
```

하여 **B 방향 RX overflow가 실제로 발생하는지** 확인합니다.

그리고 여기서 중요한 방향 수정이 하나 있습니다.

```text
A TX
  ↓
B RX
  ↓
B FIFO
```

이므로 Test 3에서 확인해야 하는 것은:

```scala
dut.io.bFifoOccupancy
dut.io.bRxOverflow
```

입니다. 이전 코드의 `aFifoOccupancy`를 읽던 부분은 잘못된 것이어서 이번 최종본에서 수정했습니다.

또한 `rxOverflow`가 **1-cycle pulse일 가능성**을 고려하여 마지막 순간의 값을 검사하지 않고, simulation 중 한 번이라도 `true`가 되었는지를 `bOverflowObserved`에 기록하도록 변경했습니다.

이 버전을 **최종 `UartDuplexSystemSim.scala` 기준본**으로 사용하면 됩니다.
