네. 업스트림 GitHub의 현재 `master` 소스를 기준으로 다시 맞추겠습니다. 방금 확인한 실제 정의에서 핵심은 다음입니다.

- `IBusSimplePlugin.setup()`에서 이미 `iBus = master(IBusSimpleBus(this))`를 생성합니다.
- 따라서 SoC 쪽에서 `master(plugin.iBus)`를 다시 호출하면 안 됩니다.
- `DBusSimplePlugin.build()`에서도 자체적으로 `dBus = master(DBusSimpleBus(...))`를 생성합니다.
- `IBusSimpleBus`의 `cmd`는 `Stream`, `rsp`는 `Flow`입니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

따라서 이전 `VexRiscvTop.scala`를 통째로 다음처럼 교체하는 것이 맞습니다.

## 1. `VexRiscvTop.scala` 교체

```scala
package myvexsoc

import spinal.core._
import vexriscv._
import vexriscv.plugin._

class VexRiscvTop extends Component {

  val io = new Bundle {
    // ------------------------------------------------------------------------
    // Debug signals
    // ------------------------------------------------------------------------

    val debugIbusValid = out Bool ()
    val debugIbusReady = out Bool ()
    val debugIbusPc    = out UInt (32 bits)

    val debugRspValid = out Bool ()
    val debugRspInst  = out Bits (32 bits)

    val debugDmemValid = out Bool ()
    val debugDmemWr    = out Bool ()
    val debugDmemAddr  = out UInt (32 bits)
    val debugDmemData  = out Bits (32 bits)
  }

  // --------------------------------------------------------------------------
  // CPU
  // --------------------------------------------------------------------------

  val cpu = new VexRiscv(
    CpuConfig.smallest()
  )

  // --------------------------------------------------------------------------
  // Obtain the buses created by the VexRiscv plugins.
  //
  // IMPORTANT:
  // IBusSimplePlugin already creates:
  //
  //   iBus = master(IBusSimpleBus(this))
  //
  // Therefore we must NOT call master(plugin.iBus) here.
  // --------------------------------------------------------------------------

  val iBusPlugin =
    cpu.config.plugins
      .collectFirst {
        case plugin: IBusSimplePlugin => plugin
      }
      .get

  val dBusPlugin =
    cpu.config.plugins
      .collectFirst {
        case plugin: DBusSimplePlugin => plugin
      }
      .get

  val iBus = iBusPlugin.iBus
  val dBus = dBusPlugin.dBus

  // We are going to connect these buses directly to our SoC logic.
  iBus.setAsDirectionLess()
  dBus.setAsDirectionLess()

  // --------------------------------------------------------------------------
  // Instruction ROM
  // --------------------------------------------------------------------------

  val rom = new InstructionRom(
    baseAddress = 0x80000000L,
    wordCount   = 16
  )

  // CPU -> ROM
  rom.io.cmdValid := iBus.cmd.valid
  rom.io.cmdPc    := iBus.cmd.pc

  // ROM -> CPU
  iBus.cmd.ready := rom.io.cmdReady

  iBus.rsp.valid := rom.io.rspValid
  iBus.rsp.error := rom.io.rspError
  iBus.rsp.inst  := rom.io.rspInst

  // --------------------------------------------------------------------------
  // Data bus
  //
  // No RAM yet.
  //
  // cmd.ready:
  //   Memory side tells CPU that a request can be accepted.
  //
  // rsp.error / rsp.data:
  //   Memory side supplies the response.
  //
  // rsp.ready is driven by the CPU, so we do NOT drive it here.
  // --------------------------------------------------------------------------

  dBus.cmd.ready := True

  dBus.rsp.error := False
  dBus.rsp.data  := B(0, 32 bits)

  // --------------------------------------------------------------------------
  // Debug outputs
  // --------------------------------------------------------------------------

  io.debugIbusValid := iBus.cmd.valid
  io.debugIbusReady := iBus.cmd.ready
  io.debugIbusPc    := iBus.cmd.pc

  io.debugRspValid := iBus.rsp.valid
  io.debugRspInst  := iBus.rsp.inst

  io.debugDmemValid := dBus.cmd.valid
  io.debugDmemWr    := dBus.cmd.wr
  io.debugDmemAddr  := dBus.cmd.address
  io.debugDmemData  := dBus.cmd.data
}
```

### 이전 코드와 가장 중요한 차이

잘못된 코드는:

```scala
iBus = master(plugin.iBus)
```

였습니다.

현재 업스트림에서는 `plugin.iBus` 자체가 이미:

```scala
iBus = master(IBusSimpleBus(this))
```

로 만들어져 있습니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

그래서 우리는 단순히:

```scala
val iBus = iBusPlugin.iBus
```

로 가져와서 사용하는 것입니다.

## 2. DBus에서도 수정된 부분

이 부분도 중요합니다.

이전 코드에는:

```scala
dBus.rsp.ready := True
```

가 있었는데 **이것도 제거했습니다.**

현재 업스트림 `DBusSimpleRsp`는:

```scala
val ready = Bool
val error = Bool
val data  = Bits(32 bits)
```

이고 `DBusSimpleBus.asMaster()`에서 `ready/error/data`가 CPU 쪽 출력으로 정의됩니다. 즉 `ready`는 CPU가 생성하는 신호입니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/DBusSimplePlugin.scala?utm_source=chatgpt.com)

따라서 이번에는:

```scala
dBus.rsp.error := False
dBus.rsp.data  := B(0, 32 bits)
```

만 연결합니다.

# 4. 그리고 한 가지 중요한 점

현재 업스트림 `IBusSimplePlugin`에는:

```scala
val busLatencyMin: Int = 1
```

이 있고, fetch response를 내부에서 `StreamFifoLowLatency` 등을 이용해 처리합니다. 따라서 우리가 만든 ROM에서 **1-cycle response**를 사용하는 방향은 이 CPU 설정과 자연스럽게 맞습니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

즉 현재 구조는:

```text
             cycle N
                │
                ▼
       iBus.cmd.valid
       iBus.cmd.pc
                │
                ▼
        InstructionRom
                │
             1 cycle
                │
                ▼
       iBus.rsp.valid
       iBus.rsp.inst
                │
                ▼
             VexRiscv
```

입니다.

## `VexRiscvTopSim.scala` 수정

다음 부분을 전부 `dut.io.xxx`로 바꾸면 됩니다.

```scala
package myvexsoc

import spinal.core.sim._

object VexRiscvTopSim extends App {

  SimConfig
    .withWave
    .allOptimisation
    .compile(new VexRiscvTop)
    .doSim { dut =>

      dut.clockDomain.forkStimulus(period = 10)

      // ----------------------------------------------------------------------
      // Reset
      // ----------------------------------------------------------------------

      dut.clockDomain.resetSim #= true

      dut.clockDomain.waitSampling(5)

      dut.clockDomain.resetSim #= false

      println()
      println("==============================================")
      println(" VexRiscv + Instruction ROM simulation")
      println("==============================================")
      println()

      // ----------------------------------------------------------------------
      // Fixed number of cycles.
      //
      // No unbounded while-loop.
      // ----------------------------------------------------------------------

      for (cycle <- 0 until 40) {

        dut.clockDomain.waitSampling()

        val ibusValid =
          dut.io.debugIbusValid.toBoolean

        val ibusReady =
          dut.io.debugIbusReady.toBoolean

        val pc =
          dut.io.debugIbusPc.toBigInt

        val rspValid =
          dut.io.debugRspValid.toBoolean

        val rspInst =
          dut.io.debugRspInst.toBigInt

        val dmemValid =
          dut.io.debugDmemValid.toBoolean

        // --------------------------------------------------------------------
        // Instruction bus
        // --------------------------------------------------------------------

        if (ibusValid && ibusReady) {
          println(
            f"Cycle ${cycle + 1}%2d : " +
            f"IBUS PC=0x$pc%08X"
          )
        }

        // --------------------------------------------------------------------
        // Instruction response
        // --------------------------------------------------------------------

        if (rspValid) {
          println(
            f"             RSP INST=0x$rspInst%08X"
          )
        }

        // --------------------------------------------------------------------
        // Data bus
        // --------------------------------------------------------------------

        if (dmemValid) {

          val wr =
            dut.io.debugDmemWr.toBoolean

          val addr =
            dut.io.debugDmemAddr.toBigInt

          val data =
            dut.io.debugDmemData.toBigInt

          println(
            f"             DBUS ${if (wr) "WRITE" else "READ "} " +
            f"ADDR=0x$addr%08X DATA=0x$data%08X"
          )
        }
      }

      println()
      println("Simulation finished.")
      println()
    }
}
```

### 원인

현재 업스트림 `Pipeline.build()`가 `Component.current.addPrePopTask(() => build())`로 등록되어 있습니다. 즉 `new VexRiscv(...)`가 반환되는 순간에는 아직 plugin의 `setup()`/`build()`가 실행되지 않았습니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/master/src/main/scala/vexriscv/Pipeline.scala)

그리고 실제 `IBusSimplePlugin.setup()`에서:

```scala
iBus = master(IBusSimpleBus(this)).setName("iBus")
```

가 실행됩니다. 즉 그 전에는 `plugin.iBus == null`입니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala)

그래서 우리가 이전에 작성한:

```scala
val iBus = iBusPlugin.iBus
iBus.setAsDirectionLess()
```

가 **너무 일찍 실행되어 NPE**가 난 것입니다.

업스트림 공식 예제가 정확히 이 문제를 피하는 방법을 보여줍니다. `new VexRiscv(...)` 직후 `cpu.rework { ... }` 안에서 `plugin.iBus`를 사용합니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/demo/VexRiscvAxi4WithIntegratedJtag.scala?utm_source=chatgpt.com)

# `VexRiscvTop.scala`를 다시 수정합니다

그리고 이번에는 굳이 `plugin.iBus`를 외부 IO로 다시 `master()` 만들 필요도 없습니다.

우리 목적은 **CPU 내부의 `IBusSimpleBus`를 직접 ROM에 연결**하는 것이므로 `cpu.rework` 안에서 bus를 잡으면 됩니다.

다음 버전으로 **전체 교체**하세요.

```scala
package myvexsoc

import spinal.core._
import vexriscv._
import vexriscv.plugin._

class VexRiscvTop extends Component {

  val io = new Bundle {
    // ------------------------------------------------------------------------
    // Debug signals
    // ------------------------------------------------------------------------

    val debugIbusValid = out Bool ()
    val debugIbusReady = out Bool ()
    val debugIbusPc    = out UInt (32 bits)

    val debugRspValid = out Bool ()
    val debugRspInst  = out Bits (32 bits)

    val debugDmemValid = out Bool ()
    val debugDmemWr    = out Bool ()
    val debugDmemAddr  = out UInt (32 bits)
    val debugDmemData  = out Bits (32 bits)
  }

  // --------------------------------------------------------------------------
  // CPU
  // --------------------------------------------------------------------------

  val cpuConfig = CpuConfig.smallest()

  val cpu = new VexRiscv(cpuConfig)

  // --------------------------------------------------------------------------
  // CPU <-> SoC bus connection
  //
  // IMPORTANT:
  //
  // VexRiscv builds plugin buses in Pipeline.build(), which is scheduled
  // as a pre-pop task.
  //
  // Therefore plugin.iBus / plugin.dBus must be accessed from cpu.rework.
  // This is the same pattern used by the upstream VexRiscv demos.
  // --------------------------------------------------------------------------

  cpu.rework {

    var iBus: IBusSimpleBus = null
    var dBus: DBusSimpleBus = null

    for (plugin <- cpuConfig.plugins) {

      plugin match {

        case plugin: IBusSimplePlugin =>
          plugin.iBus.setAsDirectionLess()
          iBus = plugin.iBus

        case plugin: DBusSimplePlugin =>
          plugin.dBus.setAsDirectionLess()
          dBus = plugin.dBus

        case _ =>
      }
    }

    // ------------------------------------------------------------------------
    // Instruction ROM
    // ------------------------------------------------------------------------

    val rom = new InstructionRom(
      baseAddress = 0x80000000L,
      wordCount   = 16
    )

    // CPU -> ROM

    rom.io.cmdValid := iBus.cmd.valid
    rom.io.cmdPc    := iBus.cmd.pc

    // ROM -> CPU

    iBus.cmd.ready := rom.io.cmdReady

    iBus.rsp.valid := rom.io.rspValid
    iBus.rsp.error := rom.io.rspError
    iBus.rsp.inst  := rom.io.rspInst

    // ------------------------------------------------------------------------
    // Data bus
    //
    // No RAM yet.
    // ------------------------------------------------------------------------

    dBus.cmd.ready := True

    dBus.rsp.error := False
    dBus.rsp.data  := B(0, 32 bits)

    // ------------------------------------------------------------------------
    // Debug
    // ------------------------------------------------------------------------

    io.debugIbusValid := iBus.cmd.valid
    io.debugIbusReady := iBus.cmd.ready
    io.debugIbusPc    := iBus.cmd.pc

    io.debugRspValid := iBus.rsp.valid
    io.debugRspInst  := iBus.rsp.inst

    io.debugDmemValid := dBus.cmd.valid
    io.debugDmemWr    := dBus.cmd.wr
    io.debugDmemAddr  := dBus.cmd.address
    io.debugDmemData  := dBus.cmd.data
  }
}
```

## 이번 수정에서 중요한 부분

이제는:

```scala
val cpu = new VexRiscv(cpuConfig)
```

직후에

```scala
cpuConfig.plugins...
plugin.iBus
```

를 건드리지 않습니다.

대신:

```scala
cpu.rework {
    ...
    plugin.iBus.setAsDirectionLess()
    iBus = plugin.iBus
    ...
}
```

에서 접근합니다.

이것은 업스트림 VexRiscv의 공식 integration 코드와 같은 방식입니다. 공식 예제에서도 `cpu.rework` 안에서 `plugin.iBus.setAsDirectionLess()` 후 bus conversion을 수행합니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/demo/VexRiscvAxi4WithIntegratedJtag.scala?utm_source=chatgpt.com)

## 한 가지 더

`IBusSimplePlugin`의 실제 업스트림 소스를 보면 `iBus`는 `setup()`에서 생성되고 `build()`에서 `iBus.cmd`와 CPU fetch pipeline이 연결됩니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala)

따라서 이번 NPE는 단순히 `master()`가 틀렸던 문제가 아니라 **VexRiscv plugin lifecycle을 제가 앞에서 잘못 이해하고 코드를 작성한 것**입니다.

이제 이 부분은 실제 업스트림 lifecycle에 맞췄습니다.

앞으로는 다음 순서로 진행하겠습니다.

1. **업스트림 VexRiscv GitHub 소스 확인**
   - 현재 사용 중인 `master` 기준
   - `VexRiscv`
   - `Pipeline`
   - `IBusSimplePlugin`
   - `DBusSimplePlugin`
   - 관련 demo/integration 코드
   를 먼저 확인합니다.

2. **SpinalHDL lifecycle 검토**
   - `setup`
   - `build`
   - `rework`
   - `master/slave`
   - plugin bus 생성 시점
   등을 확인해서 elaboration 순서 문제가 없는지 검토합니다.

3. **현재 프로젝트의 실제 dependency와 버전 확인**
   - Scala 2.13
   - SpinalHDL 1.13.0
   - 현재 VexRiscv source
   - SnakeYAML 등 필요한 dependency

4. **코드 작성 후 정적 검토**
   - Scala 타입/API
   - Bundle 방향
   - `Stream`/`Flow`
   - null 가능성
   - assignment 방향
   - clock/reset
   - signal lifetime
   등을 확인합니다.

5. **Simulation 관점까지 검토**
   - IBus command/response latency
   - reset 이후 첫 fetch
   - `waitSampling()` 시점
   - simulation signal 접근성
   - 무한 `while`이나 race condition
   등을 확인합니다.

6. **그 다음에만 코드를 제시**
   - "일단 실행해 보고 오류를 고치자"가 아니라
