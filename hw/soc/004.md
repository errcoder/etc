네. 업스트림 GitHub의 현재 `master` 소스를 기준으로 다시 맞추겠습니다. 방금 확인한 실제 정의에서 핵심은 다음입니다.

- `IBusSimplePlugin.setup()`에서 이미 `iBus = master(IBusSimpleBus(this))`를 생성합니다.
- 따라서 SoC 쪽에서 `master(plugin.iBus)`를 다시 호출하면 안 됩니다.
- `DBusSimplePlugin.build()`에서도 자체적으로 `dBus = master(DBusSimpleBus(...))`를 생성합니다.
- `IBusSimpleBus`의 `cmd`는 `Stream`, `rsp`는 `Flow`입니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

따라서 이전 `VexRiscvTop.scala`를 통째로 다음처럼 교체하는 것이 맞습니다.

## 1. `VexRiscvTop.scala` 교체

```scala
package myvexsoc

import spinal.core._
import vexriscv._
import vexriscv.plugin._

class VexRiscvTop extends Component {

  val io = new Bundle {
    // ------------------------------------------------------------------------
    // Debug signals
    // ------------------------------------------------------------------------

    val debugIbusValid = out Bool ()
    val debugIbusReady = out Bool ()
    val debugIbusPc    = out UInt (32 bits)

    val debugRspValid = out Bool ()
    val debugRspInst  = out Bits (32 bits)

    val debugDmemValid = out Bool ()
    val debugDmemWr    = out Bool ()
    val debugDmemAddr  = out UInt (32 bits)
    val debugDmemData  = out Bits (32 bits)
  }

  // --------------------------------------------------------------------------
  // CPU
  // --------------------------------------------------------------------------

  val cpu = new VexRiscv(
    CpuConfig.smallest()
  )

  // --------------------------------------------------------------------------
  // Obtain the buses created by the VexRiscv plugins.
  //
  // IMPORTANT:
  // IBusSimplePlugin already creates:
  //
  //   iBus = master(IBusSimpleBus(this))
  //
  // Therefore we must NOT call master(plugin.iBus) here.
  // --------------------------------------------------------------------------

  val iBusPlugin =
    cpu.config.plugins
      .collectFirst {
        case plugin: IBusSimplePlugin => plugin
      }
      .get

  val dBusPlugin =
    cpu.config.plugins
      .collectFirst {
        case plugin: DBusSimplePlugin => plugin
      }
      .get

  val iBus = iBusPlugin.iBus
  val dBus = dBusPlugin.dBus

  // We are going to connect these buses directly to our SoC logic.
  iBus.setAsDirectionLess()
  dBus.setAsDirectionLess()

  // --------------------------------------------------------------------------
  // Instruction ROM
  // --------------------------------------------------------------------------

  val rom = new InstructionRom(
    baseAddress = 0x80000000L,
    wordCount   = 16
  )

  // CPU -> ROM
  rom.io.cmdValid := iBus.cmd.valid
  rom.io.cmdPc    := iBus.cmd.pc

  // ROM -> CPU
  iBus.cmd.ready := rom.io.cmdReady

  iBus.rsp.valid := rom.io.rspValid
  iBus.rsp.error := rom.io.rspError
  iBus.rsp.inst  := rom.io.rspInst

  // --------------------------------------------------------------------------
  // Data bus
  //
  // No RAM yet.
  //
  // cmd.ready:
  //   Memory side tells CPU that a request can be accepted.
  //
  // rsp.error / rsp.data:
  //   Memory side supplies the response.
  //
  // rsp.ready is driven by the CPU, so we do NOT drive it here.
  // --------------------------------------------------------------------------

  dBus.cmd.ready := True

  dBus.rsp.error := False
  dBus.rsp.data  := B(0, 32 bits)

  // --------------------------------------------------------------------------
  // Debug outputs
  // --------------------------------------------------------------------------

  io.debugIbusValid := iBus.cmd.valid
  io.debugIbusReady := iBus.cmd.ready
  io.debugIbusPc    := iBus.cmd.pc

  io.debugRspValid := iBus.rsp.valid
  io.debugRspInst  := iBus.rsp.inst

  io.debugDmemValid := dBus.cmd.valid
  io.debugDmemWr    := dBus.cmd.wr
  io.debugDmemAddr  := dBus.cmd.address
  io.debugDmemData  := dBus.cmd.data
}
```

### 이전 코드와 가장 중요한 차이

잘못된 코드는:

```scala
iBus = master(plugin.iBus)
```

였습니다.

현재 업스트림에서는 `plugin.iBus` 자체가 이미:

```scala
iBus = master(IBusSimpleBus(this))
```

로 만들어져 있습니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

그래서 우리는 단순히:

```scala
val iBus = iBusPlugin.iBus
```

로 가져와서 사용하는 것입니다.

## 2. DBus에서도 수정된 부분

이 부분도 중요합니다.

이전 코드에는:

```scala
dBus.rsp.ready := True
```

가 있었는데 **이것도 제거했습니다.**

현재 업스트림 `DBusSimpleRsp`는:

```scala
val ready = Bool
val error = Bool
val data  = Bits(32 bits)
```

이고 `DBusSimpleBus.asMaster()`에서 `ready/error/data`가 CPU 쪽 출력으로 정의됩니다. 즉 `ready`는 CPU가 생성하는 신호입니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/DBusSimplePlugin.scala?utm_source=chatgpt.com)

따라서 이번에는:

```scala
dBus.rsp.error := False
dBus.rsp.data  := B(0, 32 bits)
```

만 연결합니다.

# 4. 그리고 한 가지 중요한 점

현재 업스트림 `IBusSimplePlugin`에는:

```scala
val busLatencyMin: Int = 1
```

이 있고, fetch response를 내부에서 `StreamFifoLowLatency` 등을 이용해 처리합니다. 따라서 우리가 만든 ROM에서 **1-cycle response**를 사용하는 방향은 이 CPU 설정과 자연스럽게 맞습니다. [GitHub](https://github.com/SpinalHDL/VexRiscv/blob/master/src/main/scala/vexriscv/plugin/IBusSimplePlugin.scala?utm_source=chatgpt.com)

즉 현재 구조는:

```text
             cycle N
                │
                ▼
       iBus.cmd.valid
       iBus.cmd.pc
                │
                ▼
        InstructionRom
                │
             1 cycle
                │
                ▼
       iBus.rsp.valid
       iBus.rsp.inst
                │
                ▼
             VexRiscv
```

입니다.
