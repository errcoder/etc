SpinalHDL로 SoC(System on Chip)를 빠르게 구현하려면, CPU부터 직접 만드는 것보다 검증된 CPU 코어를 가져와서 Bus, Memory, Peripheral을 연결하는 방식을 가장 추천합니다.

특히 SpinalHDL은 RTL을 Scala 코드로 작성하므로, SoC의 구조를 Scala 컴포넌트로 구성하고 재사용하기 좋습니다.

제가 추천하는 방향은 다음과 같습니다.

# 1. 가장 추천하는 방법: VexRiscv 기반 SoC

가장 빠른 실전 구현 방법

[abopen.com](https://abopen.com/news/tom-verbeure-on-the-vexriscv-cpu-a-new-way-to-design/?utm_source=chatgpt.com)

VexRiscv는 SpinalHDL로 작성된 RISC-V CPU입니다.

이미 구현된 CPU를 활용하기 때문에 CPU의 명령어 실행 회로, Pipeline, Register File 등을 처음부터 구현할 필요가 없습니다.

주요 구성은 다음과 같습니다.

```
             +----------------------+
             |       VexRiscv       |
             |     RISC-V CPU       |
             +----------+-----------+
                        |
                  Instruction /
                    Data Bus
                        |
             +----------+-----------+
             |      Bus Fabric     |
             +----------+-----------+
                        |
          +-------------+-------------+
          |             |             |
     +----+----+   +----+----+   +----+----+
     |   RAM   |   |   ROM   |   |   APB   |
     +---------+   +---------+   +----+----+
                                      |
                            +---------+---------+
                            |         |         |
                          UART      GPIO      Timer
```

장점:

- RISC-V CPU를 직접 구현할 필요가 없음
- Instruction/Data Bus 구성 가능
- RAM, ROM 연결
- UART, GPIO, Timer 등의 Peripheral 확장
- FPGA에서 실제 동작시키는 방향으로 발전 가능
- C 프로그램을 실행하는 SoC까지 확장 가능

프로젝트 출발점으로 가장 적합합니다.

## 2. 빠른 SoC 구현을 위한 선택지

| 방법         | 특징                              | 추천 용도          |
| ---------- | ------------------------------- | -------------- |
| Murax      | CPU + RAM + UART + GPIO + Timer | 첫 SoC 구현       |
| VexRiscv   | 플러그인 기반 CPU                     | CPU 구성 변경 및 확장 |
| SaxonSoc   | 복잡한 Bus 및 Linux 지원 지향           | 고급 SoC         |
| VexiiRiscv | 차세대 RISC-V CPU 및 SoC            | 최신 아키텍처 연구     |

참고 프로젝트:

- 빠르게 동작하는 SoC를 확보하려면 Murax
- CPU 구조를 직접 변경하고 싶다면 VexRiscv
- Linux까지 고려한 확장형 SoC를 만들려면 SaxonSoc 또는 VexiiRiscv

## 4. 현재 학습 과정에서 이어가는 방법

지금까지 진행한 내용을 고려하면, 상당히 좋은 출발점에 도달했습니다.

이미 다음 내용을 구현하고 검증했습니다.

- Counter / Clock Enable / FSM
- ROM / RAM / Synchronous RAM
- ALU / Register File
- Mini CPU Datapath
- Pipeline (2\~5 Stage)
- Forwarding / Hazard Detection
- Load-use Stall / Branch Flush

특히 최근 `FiveStageLoadCpu`에서 LOAD, ADD, Forwarding, Stall, Branch Flush까지 통합 검증했습니다.

이제 CPU 내부 구조를 계속 처음부터 공부하기보다는 기존에 만든 CPU를 SoC로 확장하는 단계로 넘어가는 것을 추천합니다.
