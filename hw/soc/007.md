# 이제 올바른 방향

여기서 가장 중요한 것은 **VexRiscv의 plugin 시스템 안에서 bus를 연결하는 것**입니다.

`Pipeline.build()`의 순서는:

```text
IBusSimplePlugin.setup()
DBusSimplePlugin.setup()
...
IBusSimplePlugin.build()
DBusSimplePlugin.build()
...
```

이므로, **VexRiscv config의 plugin 목록에 우리 SoC 연결용 Plugin을 추가하고 그 Plugin의 `setup()`에서 IBus/DBus를 얻으면 됩니다.**

특히 현재 config 순서가:

```text
IBusSimplePlugin
DBusSimplePlugin
CsrPlugin
Decoder...
...
YamlPlugin
```

이므로 마지막에 우리 `SoCMemoryPlugin`을 넣으면:

```text
IBusSimplePlugin.setup()
        ↓
        iBus 생성

DBusSimplePlugin.setup()
        ↓
        dBus 생성

...

SoCMemoryPlugin.setup()
        ↓
        이미 iBus / dBus 존재
```

가 됩니다.

이것은 현재 commit의 실제 `Pipeline.build()` 구조와 정확히 맞습니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/baf7dc82f855eddaf5b0a20a6802c526f127e38/src/main/scala/vexriscv/Pipeline.scala)

---

## 따라서 더 이상 `rework` / `addPrePopTask`를 사용하지 마십시오.

다음 단계에서는 `SoCMemoryPlugin extends Plugin[VexRiscv]`를 만들어야 합니다.

그리고 이것은 단순한 임시방편이 아니라 **VexRiscv가 설계된 방식에 맞는 해결책**입니다.

### 구조

```text
VexRiscvConfig.plugins
        │
        ├─ IBusSimplePlugin
        │      └─ setup() → iBus 생성
        │
        ├─ DBusSimplePlugin
        │      └─ setup() → dBus 생성
        │
        ├─ CsrPlugin
        ├─ DecoderSimplePlugin
        ├─ ...
        │
        └─ SoCMemoryPlugin
               │
               ├─ setup()
               │    ├─ IBusSimplePlugin.iBus 획득
               │    └─ DBusSimplePlugin.dBus 획득
               │
               └─ build()
                    └─ ROM/RAM 연결
```

이 방식이면 **`iBus`가 null일 가능성이 없습니다.**  
왜냐하면 같은 `plugins.foreach(_.setup(...))` 안에서 IBus plugin이 먼저 실행되고, 우리 plugin은 그 뒤에 실행되도록 목록 순서를 명시할 수 있기 때문입니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/baf7dc82f855eddaf5b0a20a6802c526f127e38/src/main/scala/vexriscv/Pipeline.scala)

---

### 그리고 한 가지 더

지금 `assert(iBus != null)`은 **삭제하지 마십시오.**

오히려 이번 오류처럼 lifecycle을 검증하는 데 아주 유용합니다.

정상적인 최종 코드에서는:

```scala
require(iBus != null, "IBusSimplePlugin must appear before SoCMemoryPlugin")
require(dBus != null, "DBusSimplePlugin must appear before SoCMemoryPlugin")
```

처럼 명확한 오류를 내도록 만들 수 있습니다.
