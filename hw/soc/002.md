# 3. 중요한 문제: Reset Vector

현재 CPU의 시작 주소는:

```text
0x80000000
```

입니다. [GitHub](https://raw.githubusercontent.com/SpinalHDL/VexRiscv/master/src/main/scala/vexriscv/demo/GenSmallest.scala)

따라서 ROM을 단순히


로 생각하면 안 됩니다.

SoC 주소 공간을 다음과 같이 잡겠습니다.

이렇게 하면 Scala에서 VexRiscv를 구성하는 장점이 사라집니다.

우리가 원하는 최종 구조는:

```text
Scala
 │
 ├── VexRiscv
 │
 ├── ROM
 │
 ├── RAM
 │
 ├── Bus
 │
 └── UART
 │
 ▼
SpinalHDL
 │
 ▼
Verilog
 │
 ├── Simulation
 │
 └── FPGA
```

입니다.

공식 VexRiscv도 자체적으로 `GenSmallest` 같은 Configuration Generator를 제공하고 있고, CPU가 Plugin 기반으로 구성됩니다. [GitHub](https://github.com/SpinalHDL/VexRiscv?utm_source=chatgpt.com)

# 7. 이번 단계의 첫 번째 실행 목표

따라서 지금 단계의 실행 순서는 다음으로 하겠습니다.

### Step A

현재 VexRiscv 저장소에서:

```text
GenSmallest.scala
```

를 기준으로 CPU Configuration을 우리 프로젝트에 복사합니다.

### Step B

우리 프로젝트에서:

```scala
new VexRiscv(...)
```

를 생성합니다.

### Step C

Instruction Bus를 ROM에 연결합니다.

### Step D

Reset vector:

```text
0x80000000
```

부터 instruction을 공급합니다.

### Step E

SpinalSim에서:

```text
PC
IBus cmd
IBus response
```

를 확인합니다.

### Step F

VCD로 실제 Fetch waveform을 확인합니다.
