SpinalHDL로 System on Chip(SoC)을 가장 빠르고 효율적으로 구현하는 방법은 **SpinalHDL 전용 RISC-V 프로세서인 VexRiscv와 
제공되는 레퍼런스 SoC 템플릿(Murax 등), 그리고 자동화 라이브러리(`BusSlaveFactory`)를 활용하는 것** 입니다.

처음부터 모든 걸 짜는 대신, 이미 검증된 템플릿과 툴을 조합하면 몇 시간 안에 동작하는 SoC를 구축할 수 있습니다. 가장 빠른 3가지 핵심 접근법입니다.

---

### 1. `Murax` 또는 `Briey` SoC 템플릿 활용하기 (가장 빠름)

SpinalHDL 생태계에는 이미 완성된 오픈소스 RISC-V SoC 구조가 준비되어 있습니다. 
이를 수정(Customizing)하여 원하는 구조로 빠르게 탈바꿈시키는 것이 가장 빠릅니다.

* **Murax SoC (`vexriscv.demo.Murax`)**:
* 외장 메모리(SDRAM 등) 없이 FPGA 내부 자원(On-chip RAM, 8KB 등)만으로 동작하는 초경량 SoC입니다.
* VexRiscv CPU, APB3 버스, UART, Timer, GPIO, JTAG 디버거가 기본 포함되어 있습니다.
* 소스코드 구조(`src/main/scala/vexriscv/demo/Murax.scala`)를 입맛에 맞게 커스텀하여 빠르게 빌드할 수 있습니다.


* **Briey / Pinsec SoC**:
* AXI4 버스, SDRAM 컨트롤러, 캐시 등이 포함된 조금 더 고성능의 SoC 템플릿입니다.



---

### 2. `BusSlaveFactory`로 커스텀 페리페럴(Peripheral) 빠르게 만들기

SoC에 자신만의 하드웨어 가속기나 커스텀 IP를 붙일 때 가장 번거로운 작업은 **메모리 맵(Memory-mapped) 주소 복호화 및 
레지스터 인터페이스 구현** 입니다. SpinalHDL은 이를 자동화해 주는 `BusSlaveFactory`를 제공합니다.

```scala
// APB3 버스를 사용하는 커스텀 IP 페리페럴 예시
class MyCustomIP extends Component {
  val io = new Bundle {
    val bus = slave(APB3(addressWidth = 4, dataWidth = 32))
    val customSignal = out Bool()
  }

  // 레지스터 정의
  val myReg = Reg(UInt(32 bits)) init(0)
  io.customSignal := myReg(0)

  // BusSlaveFactory를 이용해 APB3 버스와 레지스터를 단 몇 줄로 매핑
  val busCtrl = Apb3SlaveFactory(io.bus)
  busCtrl.driveAndRead(myReg, address = 0x00) // 0x00 번지에 레지스터 매핑
}

```

* 수십 줄의 Verilog 주소 디코딩 로직을 작성할 필요 없이, 단 한 줄(`driveAndRead`)로 CPU가 제어할 수 있는 레지스터가 생성됩니다.

---

### 3. VexRiscv의 플러그인(Plugin) 구조 활용

SoC의 핵심인 CPU를 커스텀할 때, VexRiscv는 **플러그인 기반**으로 설계되어 있어 필요한 기능만 꼈다 뺐다 할 수 있습니다.

* 곱셈/나눗셈(MUL/DIV) 확장, 캐시(Cache), MMU(Linux 구동용), 디버그 인터페이스 등을 설정 객체(Config) 수정만으로 쉽게 조합할 수 있습니다.

---

### 🚀 추천 개발 순서 (Quick Start)

1. **SpinalTemplateSbt** 공식 템플릿 프로젝트를 클론하여 기본 개발 환경을 세팅합니다.
2. `VexRiscv` 레포지토리의 `vexriscv.demo.Murax` 코드를 참고하여 프로젝트에 SoC Top-level을 가져옵니다.
3. 필요한 자신만의 하드웨어 로직을 추가하고 `BusSlaveFactory`로 SoC 버스에 연결합니다.
4. SpinalSim을 통해 시뮬레이션 검증 후 Verilog를 생성(`sbt run`)하여 FPGA에 올립니다.
